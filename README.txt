Design direction
Warm, personal, editorial and deliberately irregular. The website avoids repeated three-card grids, numbered process blocks, fake social proof, generic “luxury” copy and heavy page transitions. Motion is limited to soft in-page reveals, small image movement and one optional immersive album overlay.

Images
The concept hotlinks public portfolio images already served from mintbysajeda.com so the prototype can show Sajeda’s existing work without bundling or redistributing the original files. Replace hotlinks with approved high-resolution client assets before launch. If any source URL changes, update the img src values.

Important
The enquiry form is a visual prototype and does not submit anywhere yet. Connect it to the client’s real form handler / CRM before publishing.
